รายละเอียดสถานีระดับน้ำ

แหล่งข้อมูล: กำลังอ่านข้อมูลจาก Google Sheets

นิยามข้อมูลและแผนพัฒนา

ต้นแบบนี้ใช้ข้อมูลจริงจาก Google Sheets แยกเป็นภาพรวมประเทศและหน้า กทม. โดยวันที่ของแต่ละแหล่งอาจไม่ตรงกัน

  1. ยอดภัย: เลือกวันรายงานเดียว นับจังหวัดไม่ซ้ำ และไม่บวกยอดครัวเรือนข้ามวัน จังหวัดที่ไม่ปรากฏในรายงานไม่เท่ากับไม่มีภัย
  2. กลุ่มเปราะบาง: จับคู่ด้วยชื่อจังหวัดและเขตสุขภาพ ใช้จำนวนทั้งจังหวัดเพื่อวางแผน ยังไม่มีข้อมูลผู้ประสบภัยจริงแยกรายเขต
  3. ความสด: ใช้เวลาวัดสถานีหรือเวลาปรับปรุงรายศูนย์เทียบเวลาดึง รายงาน ปภ. ที่มีเพียงวันหรือเวลา 00:00 ซึ่งยังไม่ยืนยันเวลาจริง และกลุ่มเปราะบางที่ไม่มีเวลา แสดงไม่ทราบเวลาข้อมูล; อายุ 0–24 ชั่วโมงเทียบเวลานำเข้า ตามเกณฑ์ในไฟล์ อายุเกิน 24 ชั่วโมงเป็นข้อมูลเก่า ค่าติดลบเป็นเวลาอนาคต ไม่จัดเป็นข้อมูลสด
  4. กทม.: แสดงสถานีที่จังหวัดในข้อมูลต้นทางเป็นกรุงเทพมหานคร
  5. ศูนย์พักพิง: จำนวนศูนย์ เขต พิกัด และผู้พักคำนวณจาก Google Sheets ทุกครั้งที่โหลดหน้า
  6. แผนที่: แสดงพิกัดที่มีจริง ไม่ประมาณพิกัดที่หาย จุดสถานีไม่ใช่ขอบเขตน้ำท่วม พื้นแผนที่ต้องใช้อินเทอร์เน็ต

ลำดับพัฒนาสู่ Google Sheets + Apps Script

  1. ตกลงนิยาม/รอบรายงาน และแก้รายการเวลาอนาคตกับศูนย์พักพิงเกินความจุ
  2. เพิ่มรหัสจังหวัด รหัสเขต และวันอ้างอิงประชากร เก็บประวัติรายงานและบันทึกการนำเข้า
  3. จัดข้อมูลใน Google Sheets แยก Raw, Master, ตัวชี้วัด และ Source log
  4. ใช้หน้า HTML นี้เป็นต้นแบบ Apps Script Web App อ่านข้อมูลผ่าน google.script.run และเก็บ cache เพื่อลดการอ่านซ้ำ
  5. เพิ่มการประเมินน้ำอุปโภคบริโภค สุขาภิบาลศูนย์พักพิง กลุ่มเปราะบางที่ได้รับผลกระทบจริง และงานสนับสนุนของกรมอนามัย
  6. ทดสอบข้อมูลเก่า/หาย/ซ้ำ และสิทธิ์ผู้ใช้ ก่อนกำหนดรอบอัปเดตและช่องทางแจ้งเตือนร่วมกับผู้รับผิดชอบ

เปิดผ่านเซิร์ฟเวอร์เพื่ออ่าน Google Sheets ใหม่ทุกครั้งที่โหลดหน้า รอ Google Sheets บันทึกสำเร็จแล้วรีเฟรช
